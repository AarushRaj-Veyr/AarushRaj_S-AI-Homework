Question Title: Data Breach Response

Question Link:
https://my.newtonschool.co/playground/code/orlr84xpc3oo?lecture_hash=vifkrugjcwth

Solution:
cd breach_response
chmod 755 evidence
cp evidence/log_dump.txt log_dump.txt
mv evidence secure
chmod 555 secure/evidence
chmod 777 reports/incident_summary.txt
echo "Breach confirmed" > reports/incident_summary.txt
echo "Escalated to security team" >> reports/incident_summary.txt
chmod 444 reports/incident_summary.txt
touch secure/forensics_report.txt
echo "Forensics Complete" > secure/forensics_report.txt
chmod 600 secure/forensics_report.txt

Approach:
1. First I Went into the folder breach_response, and then gave +x permission to evidence folder.
2. Then I copied log_dump.txt from evidence to parent directory and then moved evidence folder into secure folder.
3. Then I Restored the permissions back to default for the folder.
3. Then I Added content to incident_summary.txt by giving it +x permission and after that bringing it back to default.
4. Then I created a file forensics_report.txt, added content to it and then gave it 600 permissions.

Result:
I updated the file permissions, copied the log file, and renamed the evidence folder to secure. I added the breach and escalation messages to the incident summary and created the forensic report with the required content. Finally, I set the appropriate permissions for both reports.
